#blocks 

Code blocks are compatible with [[Color schemes]]. You can define your own syntax highlighting scheme via [[Style Settings]] plugin.

Code blocks are also compatible with [[Block width]] features.

## Hotkeys

Use [[Hotkeys]] to adjust code block width globally:

- Cycle between code block width options

## Helper classes

Use [[Helper classes]] to control code block width on a specific note:

| Class       | Description                               |
| ----------- | ----------------------------------------- |
| `code-100`  | Code blocks fill 100% of the pane width   |
| `code-max`  | Code blocks fill the max line width       |
| `code-wide` | Code blocks fill the wide line width      |

Note that Obsidian uses two different syntax highlighting libraries in Reading vs Editing mode, so the syntax highlighting may have some inconsistencies depending on the language you use.
